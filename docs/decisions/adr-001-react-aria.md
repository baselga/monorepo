# ADR 001: React Aria

- Estado: aceptada.
- Contexto: los controles UI necesitan comportamiento accesible y estados de interacción coherentes.
- Decisión: basar las interacciones de componentes en React Aria y sus subpaths.
- Consecuencia: la biblioteca conserva la apariencia en sus CSS Modules y delega la semántica/interacción accesible a los componentes React Aria.
