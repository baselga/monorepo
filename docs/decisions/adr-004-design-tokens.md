# ADR 004: Tokens por capas

- Estado: aceptada.
- Contexto: los valores visuales deben ser consistentes y adaptarse a los temas.
- Decisión: separar paletas primitivas de tokens semánticos de color, y centralizar las escalas de espacio, tipografía, radios, elevación, movimiento y capas.
- Consecuencia: los componentes consumen tokens semánticos y no duplican valores visuales crudos.
