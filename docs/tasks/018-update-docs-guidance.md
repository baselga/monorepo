# Tarea: actualizar la guía de documentación

## Objetivo

Documentar la arquitectura y el proceso de extensión de la nueva aplicación de
documentación para que futuras páginas mantengan la misma calidad.

## Alcance

- Indicar la responsabilidad de `apps/ui-dev` como documentación y demo.
- Explicar el catálogo tipado, las rutas y la plantilla de páginas.
- Describir cómo añadir una página para un componente público nuevo.
- Registrar las convenciones para playgrounds, ejemplos y API.
- Enlazar la validación requerida.

## Restricciones

- Actualizar solo documentación directamente relacionada.
- No duplicar las guías existentes de componentes, tokens o pruebas.

## Criterios de aceptación

1. Una persona contribuidora puede localizar la fuente de cada dato
   documental y el procedimiento para ampliar el sitio.
2. La guía distingue API real, ejemplos prácticos y contenido editorial.
3. Las referencias a comandos coinciden con `package.json`.

## Dependencias

- `016-review-api-documentation-model.md`.
